# Mobile detector research and decision

Reviewed official upstream documentation and available artifacts on 2026-10-25. The selection experiment measures three existing metadata-bearing exports on identical photographs. A paper's published score, a framework's name or a newer version number is not a measured SIGHT improvement.

| Option | Actual availability and deployment | License/provenance | Decision |
| --- | --- | --- | --- |
| EfficientDet-Lite0 int8 | Official version 1 MediaPipe TFLite, 320x320, 4,602,795 bytes; already works in SIGHT Android | Google AutoML upstream Apache 2.0; precise export has no separate embedded weight license, preserved NOTICE applies | Retain FAST and the original baseline |
| EfficientDet-Lite2 int8 | Official version 1 MediaPipe TFLite, 448x448, 7,515,971 bytes; same task API and 80 COCO labels | Same upstream model-family provenance and export caveat | Genuine inference winner on separate 50-photo selection split; add selective INSPECT, not continuous replacement |
| SSD MobileNetV2 float32 | Official version 1 MediaPipe TFLite, 256x256, 11,316,189 bytes; already benchmarked | TensorFlow Models Apache 2.0 provenance; same exact-export caveat | Faster desktop comparator, weaker selection AP/recall; preserve measurements |
| YOLOX nano/tiny | Upstream publishes 416x416 prebuilt ONNX artifacts, export/inference sample, and ncnn C++/Java deployment guidance | Upstream Apache 2.0; verify exact weight release provenance before distribution | Credible next comparator. Would add ONNX/ncnn preprocessing, decode/NMS and another Android native runtime; not claimed integrated or benchmarked here |
| Ultralytics YOLO | Actively available weights/export tooling for mobile runtimes | Upstream code/model terms are AGPL 3.0 or enterprise; no enterprise entitlement established in this workspace | Do not silently impose a different license on SIGHT or bundle weights; no speed/accuracy claim |
| YOLO-World | Upstream open-vocabulary model; Android export/latency requires separate validation | Upstream repository publishes GPL v3 terms | Not bundled; no open-vocabulary capability claim |
| MobileDet / SSD MobileDet CPU | Official TensorFlow Models legacy zoo has a pretrained 320x320 checkpoint/export and mobile documentation | TensorFlow Models Apache 2.0 provenance | Genuine mobile-first candidate, but no verified task-metadata-bearing artifact or new Android integration here. Older published measurements cannot establish a win over measured Lite0/Lite2 |
| LiteRT / ONNX Runtime | Supported inference runtimes, not detectors by themselves | Official open-source runtimes; weights retain their own licenses | Current MediaPipe already executes TFLite. Changing runtime alone does not add categories or accuracy; only add after an exact exported model passes preprocessing/accuracy/native tests |

Sources: [Google detector models and supported metadata](https://developers.google.com/edge/mediapipe/solutions/vision/object_detector), [EfficientDet upstream models/license](https://github.com/google/automl/tree/master/efficientdet), [YOLOX upstream](https://github.com/Megvii-BaseDetection/YOLOX), [YOLOX official ONNX models and instructions](https://github.com/Megvii-BaseDetection/YOLOX/tree/main/demo/ONNXRuntime), [Ultralytics license terms](https://www.ultralytics.com/license), [YOLO-World license](https://github.com/AILab-CVC/YOLO-World/blob/master/LICENSE), [TensorFlow MobileDet model zoo](https://github.com/tensorflow/models/blob/master/research/object_detection/g3doc/tf1_detection_zoo.md), [LiteRT](https://github.com/google-ai-edge/LiteRT), [ONNX Runtime](https://github.com/microsoft/onnxruntime).

The measured Lite2 tradeoff is better ranking and more clean held-out detections at roughly 2.8 times the paired desktop P50 cost. That supports selective reinspection, with deadlines, thermal gates and FAST fallback. It does not support running the larger model on every camera frame or assuming a physical phone will match desktop speed. The chosen .55 threshold intentionally preserves precision on calibration, and its calibration recall regression remains reported.

No model in the deployed pair adds doors, stairs, curbs, crossings, elevators, keys, identity, color recognition, metric depth or arbitrary visual-language reasoning. Those require separately licensed models, actual region evidence, privacy controls and appropriate labeled evaluation. No cloud image upload or paid service is introduced by this work.
